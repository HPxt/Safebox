# App Review Demo Account Checklist (v1)

- [ ] Demo account exists in production-like environment
- [ ] Email already confirmed
- [ ] 2FA state documented (disabled or backup code available)
- [ ] Vault pre-populated with at least 3 credentials
- [ ] Master password provided in Review Notes
- [ ] Account deletion path works in-app for demo account
- [ ] AutoFill tested on real device with this account
- [ ] Review notes include exact steps to trigger AutoFill in Safari
